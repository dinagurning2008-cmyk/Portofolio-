Body Temperature Classification Program

A Python-based program designed to classify human body temperature into medical threshold categories (hypothermia, normal, fever, and high fever) using structured conditional logic.

  • Tech Stack: Python (Conditional Logic if-elif-else, Input Validation & Output Processing).
  • Key Feature: Automatically evaluates user temperature input and maps it to accurate health categories with clear status feedback.
  • Outcome: Strengthened algorithmic problem-solving, clean code hygiene, and reproducible logic in foundational programming.
temp_classifier.py
# Temperature Classifier
def classify_temp(t):
  if t < 35.0:
    return "Hypothermia"
  elif 35.0 <= t <= 37.5:
    return "Normal"
  elif 37.6 <= t <= 39.0:
    return "Fever"
  else:
    return "High Fever"
